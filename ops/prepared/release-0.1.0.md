Stop your AI coding agent before it touches something it shouldn't.

usewarden is a local guardrail for Claude Code, Cursor, Gemini CLI, Copilot CLI, Codex and OpenCode. It blocks out-of-scope writes, `.env` reads, `rm -rf` and force pushes — with no API key, no account, and zero tokens.

This is the first real release. `0.0.0` was a name placeholder and was never a working version.

## Install

```bash
git clone https://github.com/djayamah/usewarden && cd usewarden
npm install && npm run build
node dist/src/cli.js init      # detects your agents, shows you a diff, registers hooks
node dist/src/cli.js demo      # see a real incident card in 5 seconds
node dist/src/cli.js status    # is it actually protecting you right now?
```

Node ≥ 22.13. Zero runtime dependencies. No install scripts. MIT.

## What it does

**Layer 1 — deterministic, zero tokens, every single event.** Scope globs, command patterns, protected branches, sibling-repo detection, context-fill threshold. It catches **15 of the 17** scenarios in usewarden's own sabotage suite with no model involved.

**Layer 2 — an optional, sampled LLM drift judge.** Compares what the agent is doing against the goal you declared. Runs in a detached process so it never makes your agent wait, and it can only ever *warn*. Bring your own key, or let it use a `claude` or `gemini` CLI you are already signed in to.

The ordering is fixed and not configurable: Layer 1 runs first, Layer 2 can only add findings, and **Layer 2 being down can never disable Layer 1**.

## What it cannot catch

A security tool that oversells is worse than none, so this list ships in the README and is repeated here:

- **It is not a sandbox.** It reduces blast radius; it does not contain a determined process, and it cannot stop something your policy does not name.
- **A hook that is not registered does not fire.** This is the failure the whole project is built around, which is why `usewarden status` prints **UNPROTECTED** in red and exits non-zero rather than staying quiet.
- **It trusts the agent's own report of what it is about to do.** If an agent lies about its tool input, usewarden evaluates the lie.
- **The Layer-2 judge fails open**, is sampled rather than exhaustive, and can be wrong in both directions.
- **Codex IDE and desktop wrappers may ignore project configuration entirely**, and sessions inside them are not covered. OpenCode support is a best-effort plugin shim.

## Verification in this release

- **570 tests**, no network and no API keys required, on Node 22, 24 and 25.
- **Layer-1 sabotage coverage: 15/17 (88.2%)**, measured rather than asserted.
- **22 catches from real agent sessions** across 14 transcripts, in `verification/live/`.
- **Zero runtime dependencies**, enforced by a test rather than by intention.
- Metered judge providers are marked **UNVERIFIED-LIVE** where no key was available to prove them against the vendor's live API. Gemini is verified live; Anthropic and OpenAI are contract-tested only, and the README says so in the same table rather than in a footnote.

## Also in this release

- An issue-triage bot that answers only by **quoting this repository's own documents**, with a link to every quotation. It never composes prose about the product, it declines rather than guesses, and a test now enforces that structurally rather than by convention.
- A conversation guard for the bot: it never replies to itself, never twice to the same person in a thread, never to a maintainer, and never as the third consecutive bot comment.
